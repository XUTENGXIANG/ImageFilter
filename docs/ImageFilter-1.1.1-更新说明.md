# ImageFilter 1.1.1

这一版主要是**把交互和外观收干净**：树的展开有动画了、下拉框不再用系统原生的、上下两条栏真的浮起来了。另外修掉一个「设置默认值不生效」的老 bug。

## 界面

- **缩略图网格铺满整个高度，上下两条栏真的浮在照片上。** 原来那两条栏长得像浮窗，实际各占一条实心带子 —— 766px 的内容高度里吃掉 167px，照片从它们底下滚不过去
- **下拉框全换了**：排序、星级筛选、分析结果、命名方案。圆角、展开有过渡。以前这四个是系统原生控件，读屏只会念当前值、念不出这是什么（它们都没有可访问名称）
- **「高级选项」和「筛选」展开有动画**
- **文件夹树展开/收起有动画**；树行行高 20.5 → 24px（原来低于无障碍的点击尺寸下限）
- **点设备有按下的反馈**；点完设备后目录树是渐入的，不再整块蹦出来
- 叶子图标换成了能看出文件夹造型的那个
- 去掉两处闪动：「扫描目录结构…」和「未扫描」在快盘上原来只闪一两帧

## 毛玻璃

- **默认值跟着系统走**：Win11 默认开；Win10 默认关，设置里那一项置灰并写明原因（Mica 是 Win11 才有的）
- 缩略图上的徽章改成**毛玻璃材质**：压暗改用亮度而不是平铺黑底，照片的色相留着；透光率 27% → 38%
- 重复徽章的对比度原来 3.54:1 不达标，现在 6.24:1

## 性能

- 长网格跳过屏外卡片不渲染，滚动中位帧 8.6ms → 5.8ms

## 修复

- **设置里的默认值不生效**：玻璃透明度、网格列数这些项，在从没存过值时会把默认值丢掉。表现为第一次启动玻璃透明度是 0%（应该是 70%）、网格列数掉到最少列。这个 bug 影响所有走 localStorage 的设置项
- 无障碍一批：图标按钮补上可访问名称；滑块补回焦点轮廓（原来 `outline: none` 之后没有任何替代，键盘用户看不出焦点在哪）；紧凑控件的命中区补到 24×24；尊重系统的「减少动效」
- 滑块轨道被削成梭形
- 下拉弹层被工具栏盖住半截；下拉框比同一行其它控件高 7px

## 安装

Windows 下载 `ImageFilter_1.1.1_x64-setup.exe`。macOS 见附件。

安装包没签名，SmartScreen 会提示，点「更多信息」→「仍要运行」。

从 1.1.0 升级直接覆盖安装即可，设置和 `.xmp` 开关都保留。

## 注意

- Win10 的毛玻璃行为**没有实机验证过**（手上只有 Win11）
- macOS 版一直没有实机验证过
- 文件夹树展开动画里有个 120ms 的阈值是人工观感定的；250ms 内连着展开两层，父容器可能被短暂裁掉一下
