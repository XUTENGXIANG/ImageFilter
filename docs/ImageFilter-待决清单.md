### 2. 独立评审抓到的真问题（都已修）

| 问题 | 严重度 |
|---|---|
| 我原计划里那条 `lookalike` 白名单测试是**假绿**：它从没创建共享根，所以拒绝来自"根不存在"而非"按组件比较"——**换成朴素的字符串前缀比较它照样通过** | 高（安全测试失效） |
| 越权代理建议的"防 panic"改法（`token: String::new()`）会造成 **fail-open 鉴权**：`eq_constant_time("","")` 返回 true，**空 Bearer token 就能通过** | 高（安全） |

| 规格 §5.3 的错误码表**不是实现的闭集**：漏了实现会发的 `badRequest`/`internal`，却列了服务端永不产生的 `timeout`/`network`/`serviceOff` | 中 |
| 文档声称"删掉 `canon == root_canon` 会让列共享根变 403"——**不成立**，`Path::starts_with` 是自反的 | 中（误导后人） |
