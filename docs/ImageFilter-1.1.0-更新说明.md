# ImageFilter 1.1.0

> 一句话：**筛完直接交给 Lightroom** —— 在 ImageFilter 里选好照片，一键导入并打开 LrC 的导入页面，页面上只有你选的那一批。

---

## 🆕 新增：与 Lightroom Classic 衔接（仅 Windows）

导入栏新增「**导入到 LrC**」按钮。它做的事：

1. **先把选中的照片导入**目标文件夹（原文件逐字节复制 + 双端 MD5 校验，和「导入」按钮同一条实现，不损画质）
2. **再打开 Lightroom 的导入页面**，页面上**只有这一批照片**
3. 你在 LrC 里点一次「导入」即可

- 没选目标文件夹时会先弹窗让你选
- 目标文件夹**已经有东西**时，自动导入到新建的 `ImageFilter_日期_时间` 子文件夹，再把子文件夹交给 LrC —— 这样它不会把你整个目录（旧照片、子目录、甚至目录库文件）都列出来
- 自动定位 Lightroom 安装位置（即使在非标准目录；靠 `.lrcat` 文件关联反查）
- **Lightroom 已经开着时不会静默失败**：Adobe 会忽略这时传入的路径，所以会弹框让你选「关掉后重试」或「强制关闭并继续」（后者会丢失未保存的调整，只能由你确认）
- 导入与启动各自都有进度提示（模态进度框 + 底部状态行）

> 「导入 N 张」按钮**行为完全不变**，两个入口互不影响。

## 🆕 新增：初筛流程更好用

- **评分后自动前进** —— 打完分自动跳到下一张，翻到最后一张自动回到网格。可在设置里关闭
- **撤销 / 重做** —— `Ctrl+Z` / `Ctrl+Shift+Z`，覆盖星级与勾选
- **1:1 实际像素查看** —— 查看器里按 `Z`，以鼠标位置为锚点放大，用来确认对焦到底准不准；再按一次回到适应窗口
- **颜色标签** —— `Ctrl+1`~`Ctrl+5` 打标、`Ctrl+0` 清除（快捷键修饰键可在设置里换成 `Alt`）
- **三维叠加筛选** —— 星级 + 颜色标签 + 分析结果（只看模糊 / 只看重复 / 只看最佳）任意组合，另有排序方向切换

## 🆕 新增：归档与互通

- **评分与颜色标签写入 `.xmp` 边车** —— 决策跟着照片走，换电脑、换盘符都不丢，Lightroom / digiKam 等软件也能读到。三档开关（关闭 / 询问 / 写入），**缺省是「询问」**：首次写盘前问你一次。只增改 `.xmp`，绝不动你的照片
- **导入时连同 `.xmp` 一起复制**，名字跟着照片走（照片被改成 `_1` 时边车也跟着改）
- **命名方案预设** —— 把常用的「目录模板 + 文件名模板」存下来复用，不用每次重填
- **导入历史** —— 可回查每次导入的「源文件 → 归档路径」，`{seq}` 改名后原文件名也能找回来
- **导入结果统计更准** —— 分别报「成功 / 改名 / 已跳过 / 失败」；以前"目标已存在且相同"的跳过会被错算成失败。`{seq}` 序号改为按输入顺序编号，不再因跳过而错位

## 🔧 修复（原计划的 1.0.2 内容已并入本次）

- 大光圈虚化背景的照片**不再被误标「模糊」**（旧指标衡量的是亮度离散度，与对焦无关）
- 连拍组内「最佳」改为**兼顾曝光**，不再推荐过曝/欠曝那张
- 重复标记大幅收敛：只归并「几乎同一张」（不同场景的误判从 15/371 降到 4/371）
- AI 分析耗时大降（开发环境 29 张 **63s → 5.7s**）
- 连续切换设备不再触发整盘遍历、不再把 CPU 打满
- 修复：查看器内评分会误改另一张照片、开着星级筛选时查看器崩溃或跳图、导入的文件夹层级被压平、浅色主题部分文字看不清、某类 RAW 预览空白且分析被静默跳过

## 安装

| 平台 | 说明 |
|---|---|
| **Windows 10/11** | 下载 `ImageFilter_1.1.0_x64-setup.exe`（推荐）或 `.msi` |
| macOS | 见下方 Releases 附件（Universal，Intel + Apple Silicon） |

- 安装包**未做代码签名**，Windows SmartScreen 可能提示，点「更多信息 → 仍要运行」即可
- 从 1.0.1 升级：浏览 RAW 时会**重建一次预览缓存**，属预期行为

---

## 注意

- **「导入到 LrC」目前仅 Windows**：Lightroom 衔接依赖 Windows 的注册表与进程机制；macOS 上该入口会自动隐藏
- **macOS 版仍未实机验证**（自 1.0 起就如此），欢迎提交 issue
- `.xmp` 写入的缺省档位从「关闭」改成了「询问」：第一次打分/打标时你会看到一次询问框，选「只写本机」即回到以前的行为
