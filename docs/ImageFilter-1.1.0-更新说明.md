# ImageFilter 1.1.0

主要加了一件事：**筛完直接交给 Lightroom**。

## 导入到 LrC（仅 Windows）

导入栏多了一个「导入到 LrC」按钮。点了以后：

1. 先把选中的照片导入目标文件夹（原文件直接复制 + MD5 校验，不损画质）
2. 打开 Lightroom 的导入页面，页面上只有这一批
3. 你在 LrC 里点一次导入

几点说明：

- 没选目标文件夹会先让你选
- 目标文件夹不空的话，照片先导进一个新建的 `ImageFilter_日期_时间` 子文件夹，再把子文件夹交给 LrC。不然它会把整个目录列出来
- Lightroom 装在哪会自动找（装在非标准目录也能找到）
- **LrC 已经开着的时候路径参数会被 Adobe 忽略**，所以会弹框让你选：关掉重试，或者强制关闭再继续

原来的「导入 N 张」按钮没动。

## 筛选

- 打分后自动跳下一张（可在设置里关）
- `Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做（星级和勾选）
- 查看器里按 `Z` 切 1:1，以鼠标位置为中心
- `Ctrl+1`~`Ctrl+5` 打颜色标签，`Ctrl+0` 清除
- 筛选能叠加：星级 + 颜色标签 + 分析结果（模糊/重复/最佳）

## 归档

- 星级和颜色标签可以写进 `.xmp`，跟着照片走，Lightroom 也能读。三档开关，默认「询问」——第一次写盘前问你一次。只增改 `.xmp`，不动照片
- 导入时 `.xmp` 一起复制
- 命名方案可以存下来复用
- 加了导入历史，能查每张照片从哪来、到哪去

## 修复

原来打算发 1.0.2 的那批修复并进来了：

- 大光圈虚化的照片不再被误判成模糊
- 连拍选最佳时会看曝光，不再挑过曝或欠曝那张
- 重复标记少了很多
- AI 分析快了不少（29 张 63 秒 → 5.7 秒）
- 连点设备不再整盘扫描、CPU 不再打满
- 还有几个：查看器里打分改错照片、开着星级筛选时查看器崩溃、导入的文件夹层级被压平、导入统计把"跳过"算成"失败"

## 安装

Windows 下载 `ImageFilter_1.1.0_x64-setup.exe`。macOS 见附件。

安装包没签名，SmartScreen 会提示，点「更多信息」→「仍要运行」。

从 1.0.1 升级的话，第一次浏览 RAW 会重建预览缓存，正常现象。

## 注意

- 「导入到 LrC」只有 Windows 能用，macOS 上不显示这个按钮
- macOS 版一直没有实机验证过
- `.xmp` 默认档位从「关闭」改成了「询问」
