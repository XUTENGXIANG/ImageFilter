# ImageFilter 1.1.2

小版本：设置里能查更新了，另外修掉两个看得见的毛病。

## 新增

- **设置里能检查更新。** 版本号旁边多了一个按钮，比对本机版本和 GitHub 上的最新正式版。
  五种状态共用一个按钮（检查更新 / 正在检查… / 已是最新 / 有新版本 x.y.z / 检查失败，重试），
  结果只换按钮自己的字面，不动布局。有新版时点一下直接打开下载页。
- 只在点的时候查，不会在后台偷偷联网；只比版本号，不自动下载、不静默安装。

## 修复

- **设置里的版本号是写死的。** 它一直显示 1.1.0 —— 装着 1.1.1 也显示 1.1.0。现在读的是这个二进制自己的版本号。
- **「筛选」展开后那一行太挤。** 面板里的控件贴在第一行控件下面（实测只剩 2px，像被上一行压住）。
  现在上下各留 12px；展开后整条栏 94 → 108px，网格两端留白照旧 12px 不变。

## 安装

Windows 下载 `ImageFilter_1.1.2_x64-setup.exe`。macOS 见附件。

安装包没签名，SmartScreen 会提示，点「更多信息」→「仍要运行」。

从 1.1.0 / 1.1.1 升级直接覆盖安装即可，设置和 `.xmp` 开关都保留。

## 注意

- 「检查更新」走 GitHub 的公开接口，不登录时限额 60 次/小时/IP。超了会照实显示「检查失败：HTTP 403」，不会假装已是最新
- Win10 的毛玻璃行为**没有实机验证过**（手上只有 Win11）
- macOS 版一直没有实机验证过
