# ImageFilter 更新说明

> 本文件合并了 1.1.0 起的更新说明；后续版本按同样格式往下追加。
> 更早版本见 git 历史 / GitHub Releases。

## 发布约束（GitHub Release）

从 1.3.0 起，GitHub Release 的简介统一使用下面的模板：

```text
ImageFilter vx.x.x
新增功能：
- ...
```

- 第一行固定为 `ImageFilter v<版本>`，版本号与 `package.json` / `tauri.conf.json` /
  `Cargo.toml` / `android/version.properties` 一致。
- 必须包含 `新增功能：` 段；每条一行，面向用户说明可见变化。
- 发布前按本文件对应版本段落填写，不要留模板占位。

## 通用安装与升级

- **Windows**：下载 `ImageFilter_x64-setup.exe`（推荐）或 `.msi`。安装包未签名，
  SmartScreen 提示时点「更多信息 → 仍要运行」。
- **macOS**：见 Releases 附件；当前仍缺乏实机验证。
- **Android**：`ImageFilter-Mobile-<version>.apk`，侧载安装；需与桌面端在同一局域网。
- 覆盖升级保留设置与 `.xmp` 开关；从 1.0.1 升级后首次浏览 RAW 会重建预览缓存，
  属正常现象。
- 版本号必须同步 4 处（`package.json` / `tauri.conf.json` / `Cargo.toml` /
  `settings-dialog.tsx` 的关于对话框），安卓另由 `android/version.properties` 校验。

## 1.1.2

小版本：设置里能查更新了，另外修掉两个看得见的毛病。

### 新增

- **设置里能检查更新。** 版本号旁边多了一个按钮，比对本机版本和 GitHub 上的最新正式版。
  五种状态共用一个按钮（检查更新 / 正在检查… / 已是最新 / 有新版本 x.y.z / 检查失败，重试），
  结果只换按钮自己的字面，不动布局。有新版时点一下直接打开下载页。
- 只在点的时候查，不会在后台偷偷联网；只比版本号，不自动下载、不静默安装。

### 修复

- **设置里的版本号是写死的。** 它一直显示 1.1.0 —— 装着 1.1.1 也显示 1.1.0。
  现在读的是这个二进制自己的版本号。
- **「筛选」展开后那一行太挤。** 面板里的控件贴在第一行控件下面（实测只剩 2px，
  像被上一行压住）。现在上下各留 12px；展开后整条栏 94 → 108px，网格两端留白照旧
  12px 不变。

### 注意

- 「检查更新」走 GitHub 的公开接口，不登录时限额 60 次/小时/IP。超了会照实显示
  「检查失败：HTTP 403」，不会假装已是最新。
- Win10 的毛玻璃行为**没有实机验证过**（手上只有 Win11）。
- macOS 版一直没有实机验证过。

## 1.1.1

这一版主要是**把交互和外观收干净**：树的展开有动画了、下拉框不再用系统原生的、
上下两条栏真的浮起来了。另外修掉一个「设置默认值不生效」的老 bug。

### 界面

- **缩略图网格铺满整个高度，上下两条栏真的浮在照片上。** 原来那两条栏长得像浮窗，
  实际各占一条实心带子 —— 766px 的内容高度里吃掉 167px，照片从它们底下滚不过去。
- **下拉框全换了**：排序、星级筛选、分析结果、命名方案。圆角、展开有过渡。
  以前这四个是系统原生控件，读屏只会念当前值、念不出这是什么（它们都没有可访问名称）。
- **「高级选项」和「筛选」展开有动画。**
- **文件夹树展开/收起有动画**；树行行高 20.5 → 24px（原来低于无障碍的点击尺寸下限）。
- **点设备有按下的反馈**；点完设备后目录树是渐入的，不再整块蹦出来。
- 叶子图标换成了能看出文件夹造型的那个。
- 去掉两处闪动：「扫描目录结构…」和「未扫描」在快盘上原来只闪一两帧。

### 毛玻璃

- **默认值跟着系统走**：Win11 默认开；Win10 默认关，设置里那一项置灰并写明原因
  （Mica 是 Win11 才有的）。
- 缩略图上的徽章改成**毛玻璃材质**：压暗改用亮度而不是平铺黑底，照片的色相留着；
  透光率 27% → 38%。
- 重复徽章的对比度原来 3.54:1 不达标，现在 6.24:1。

### 性能

- 长网格跳过屏外卡片不渲染，滚动中位帧 8.6ms → 5.8ms。

### 修复

- **设置里的默认值不生效**：玻璃透明度、网格列数这些项，在从没存过值时会把默认值丢掉。
  表现为第一次启动玻璃透明度是 0%（应该是 70%）、网格列数掉到最少列。这个 bug 影响
  所有走 localStorage 的设置项。
- 无障碍一批：图标按钮补上可访问名称；滑块补回焦点轮廓（原来 `outline: none` 之后
  没有任何替代，键盘用户看不出焦点在哪）；紧凑控件的命中区补到 24×24；尊重系统的
  「减少动效」。
- 滑块轨道被削成梭形。
- 下拉弹层被工具栏盖住半截；下拉框比同一行其它控件高 7px。

### 注意

- Win10 的毛玻璃行为**没有实机验证过**（手上只有 Win11）。
- macOS 版一直没有实机验证过。
- 文件夹树展开动画里有个 120ms 的阈值是人工观感定的；250ms 内连着展开两层，
  父容器可能被短暂裁掉一下。

## 1.1.0

主要加了一件事：**筛完直接交给 Lightroom**。

### 导入到 LrC（仅 Windows）

导入栏多了一个「导入到 LrC」按钮。点了以后：

1. 先把选中的照片导入目标文件夹（原文件直接复制 + MD5 校验，不损画质）
2. 打开 Lightroom 的导入页面，页面上只有这一批
3. 你在 LrC 里点一次导入

几点说明：

- 没选目标文件夹会先让你选。
- 目标文件夹不空的话，照片先导进一个新建的 `ImageFilter_日期_时间` 子文件夹，
  再把子文件夹交给 LrC。不然它会把整个目录列出来。
- Lightroom 装在哪会自动找（装在非标准目录也能找到）。
- **LrC 已经开着的时候路径参数会被 Adobe 忽略**，所以会弹框让你选：关掉重试，
  或者强制关闭再继续。

原来的「导入 N 张」按钮没动。

### 筛选

- 打分后自动跳下一张（可在设置里关）。
- `Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做（星级和勾选）。
- 查看器里按 `Z` 切 1:1，以鼠标位置为中心。
- `Ctrl+1`~`Ctrl+5` 打颜色标签，`Ctrl+0` 清除。
- 筛选能叠加：星级 + 颜色标签 + 分析结果（模糊/重复/最佳）。

### 归档

- 星级和颜色标签可以写进 `.xmp`，跟着照片走，Lightroom 也能读。三档开关，
  默认「询问」——第一次写盘前问你一次。只增改 `.xmp`，不动照片。
- 导入时 `.xmp` 一起复制。
- 命名方案可以存下来复用。
- 加了导入历史，能查每张照片从哪来、到哪去。

### 修复

原来打算发 1.0.2 的那批修复并进来了：

- 大光圈虚化的照片不再被误判成模糊。
- 连拍选最佳时会看曝光，不再挑过曝或欠曝那张。
- 重复标记少了很多。
- AI 分析快了不少（29 张 63 秒 → 5.7 秒）。
- 连点设备不再整盘扫描、CPU 不再打满。
- 还有几个：查看器里打分改错照片、开着星级筛选时查看器崩溃、导入的文件夹层级被压平、
  导入统计把"跳过"算成"失败"。

### 注意

- 「导入到 LrC」只有 Windows 能用，macOS 上不显示这个按钮。
- macOS 版一直没有实机验证过。
- `.xmp` 默认档位从「关闭」改成了「询问」。

## 1.3.0

### 新增功能

- 设置界面重新排版：玻璃标题栏、滚动渐隐、分组分隔线、键盘焦点环；禁用项直接写明原因。
- 二维码连接改为可折叠的「用手机扫码连接」按钮。
- 移除设置里的「最近连接」面板。
- 统一按钮、分段控件和滑块；滑块显示当前值、已选进度，支持键盘调整，轨道与手柄圆角对齐。
- 新增语义色令牌（品牌 / 危险 / 警告 / 信息），深色和浅色主题统一。
- 字体分层：正文 Geist + 系统中文字体，展示性标题使用衬线字体。
- 轻提示分成功 / 失败 / 信息三种配色，并支持读屏播报；toast 和 tooltip 挂到顶层，不再被面板或弹窗遮挡。
- 文档与规范：新增文档索引、SDD 生命周期和归档；`ui-craft` 补齐组件、状态、无障碍、反馈、滑块等规则。
