3. assembleRelease **带**签名环境变量(正式路径, 用一次性测试 keystore)
-----------------------------------------------------------------------
说明: 正式发布 keystore 是**人工资产**, 必须由人按 docs/ImageFilter-安卓发版与签名.md §2
生成并备份。本次为了证明"环境变量这条路真的通", 在 **A:\tenent\.scratch\**(gitignore)
临时生成了一把**一次性测试 keystore**(密码 m4t4-throwaway, 仅本机, 已声明作废),
用它跑通了正式签名路径。**它不是**项目要长期使用的那把。

命令: keytool -genkeypair -keystore .scratch/m4t4-release-test.keystore -alias imagefilter
        -keyalg RSA -keysize 4096 -validity 10000 -storetype PKCS12
        -dname "CN=ImageFilter Mobile, O=XUTENGXIANG, C=CN"
      gradlew --no-daemon assembleRelease       (四个 IMAGEFILTER_* 均已设置)
结果: BUILD SUCCESSFUL in 17s;日志中**没有**回退警告(有密钥时不警告, 符合预期)
产物: app-release.apk = 7,944,730 字节(7.58 MiB)
signingConfig = release (不是 debug)

签名自证: apksigner verify --print-certs
  Signer #1 certificate DN: CN=ImageFilter Mobile, O=XUTENGXIANG, C=CN
  Signer #1 certificate SHA-256 digest: b0a5d421e38e0a2dc7e0f30fbbada7924810d5faf4a6286999e34dd038f9560c
keytool -list -v 同一把 keystore 的指纹:
  SHA256: B0:A5:D4:21:E3:8E:0A:2D:C7:E0:F3:0F:BB:AD:A7:92:48:10:D5:FA:F4:A6:28:69:99:E3:4D:D0:38:F9:56:0C
=> 两者一致: APK 就是这把 keystore 签的, Gradle 的环境变量读取路径可用。
SIGNING-PROVENANCE.txt 也如实写成 "签名=发布密钥"。
